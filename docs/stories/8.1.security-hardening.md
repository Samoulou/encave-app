# Story 8.1: Security Hardening

## Status

Draft

## Story

**As a** platform operator,
**I want** all security vulnerabilities fixed and proper security headers in place,
**so that** user data is protected and the platform meets security standards.

## Issues Addressed

| Issue ID | Severity | Description |
|----------|----------|-------------|
| SEC-001 | P0 | Secrets exposés dans Git |
| SEC-002 | P0 | AccessToken stocké en plaintext |
| SEC-003 | P1 | Security headers manquants (CSP, HSTS) |
| SEC-004 | P1 | Unsubscribe token sans expiration |
| SEC-005 | P2 | Complexité password insuffisante |
| SEC-006 | P2 | Rate limiter in-memory non scalable |

## Acceptance Criteria

### AC1: Secrets Rotation (P0 - SEC-001)
1. Generate new `AUTH_SECRET` (min 32 chars, random)
2. Create new database user with strong password
3. Regenerate `STRIPE_SECRET_KEY` in Stripe Dashboard
4. Regenerate `STRIPE_WEBHOOK_SECRET` and `STRIPE_CONNECT_WEBHOOK_SECRET`
5. Regenerate `BLOB_READ_WRITE_TOKEN`
6. Clean Git history with `git filter-repo` or BFG
7. Verify `.gitignore` prevents future commits of `.env*`

### AC2: AccessToken Fix (P0 - SEC-002)
1. Remove `accessToken` plaintext field from Booking model
2. Keep only `accessTokenHash` for verification
3. Update `getBookingByToken()` to hash input before comparison
4. Migration: Set existing `accessToken` fields to null

### AC3: Security Headers (P1 - SEC-003)
1. Add `Content-Security-Policy` header in `next.config.js`
2. Add `X-Frame-Options: SAMEORIGIN`
3. Add `X-Content-Type-Options: nosniff`
4. Add `X-XSS-Protection: 1; mode=block`
5. Add `Referrer-Policy: strict-origin-when-cross-origin`
6. Add `Strict-Transport-Security: max-age=31536000; includeSubDomains`
7. Add `Permissions-Policy: geolocation=(), microphone=(), camera=()`
8. Test with securityheaders.com (target: A+ rating)

### AC4: Unsubscribe Token Expiration (P1 - SEC-004)
1. Add `unsubscribeTokenExpiresAt` field to NotificationPreferences
2. Set expiration to 30 days from creation
3. Validate expiration in `/api/unsubscribe/[token]` route
4. Regenerate token on expiration

### AC5: Password Complexity (P2 - SEC-005)
1. Update `passwordSchema` in `src/lib/validators/auth.ts`
2. Require: 1 uppercase, 1 lowercase, 1 special character
3. Update password hint text in registration form
4. Update translations for new validation messages

### AC6: Rate Limiter Scalability (P2 - SEC-006)
1. Configure Upstash Redis for production
2. Add environment check to force Redis in production
3. Keep in-memory for development

### Technical Implementation

```typescript
// next.config.js - Security Headers
const securityHeaders = [
  {
    key: 'Content-Security-Policy',
    value: "default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' https: data:; font-src 'self' https:; connect-src 'self' https://api.stripe.com https://checkout.stripe.com; frame-src https://checkout.stripe.com https://js.stripe.com;"
  },
  { key: 'X-Frame-Options', value: 'SAMEORIGIN' },
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'X-XSS-Protection', value: '1; mode=block' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
  { key: 'Strict-Transport-Security', value: 'max-age=31536000; includeSubDomains' },
  { key: 'Permissions-Policy', value: 'geolocation=(), microphone=(), camera=()' },
];

module.exports = {
  async headers() {
    return [
      {
        source: '/:path*',
        headers: securityHeaders,
      },
    ];
  },
};
```

### Git History Cleaning

```bash
# Using BFG Repo-Cleaner
java -jar bfg.jar --delete-files .env* --no-blob-protection
git reflog expire --expire=now --all
git gc --prune=now --aggressive
git push origin --force --all
```

### Risk Mitigation

- **Primary Risk:** Auth flow could break after secret rotation
- **Mitigation:** Test auth flow thoroughly before production deployment
- **Rollback Plan:** Keep old secrets in secure backup until verified
