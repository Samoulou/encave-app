# Story 12.4: Experience Creation & Duplication Fixes

## Status

Draft

## Story

**As a** winemaker creating and managing experiences,
**I want** a clear, intuitive creation flow with working preview and duplication features,
**so that** I can efficiently set up and manage my wine experiences.

## Problem Statement

User feedback identified 9 issues with the experience creation and management flow:

1. **Confusing Min Guests**: "Min guests" field is unclear - users expect it to mean "minimum for event to happen" but it's implemented as "minimum per booking"
2. **Validation Too Strict**: 100 character minimum for description is too restrictive
3. **Missing Publish Prompt**: No prompt to publish after creation - users forget and leave events in draft
4. **Preview Broken**: Preview returns 404 with "Missing required html tags" error
5. **Preview Loader Stuck**: Loading indicator remains after preview attempt
6. **Duplication Default**: Duplicated experiences should default to unpublished status
7. **Duplication Bug**: Both original and duplicate switch to draft after duplication
8. **Time Slots Missing**: Time slots are not copied when duplicating an experience

## Acceptance Criteria

### AC1: Clarify Min/Max Guests Semantics
1. Rename "Min guests" to clearer label (e.g., "Minimum booking size")
2. Add help tooltip explaining the field
3. Consider adding separate "Minimum to confirm event" field (future)
4. Update all translations (FR, EN, DE)

### AC2: Relax Description Validation
1. Remove or reduce minimum character requirement for description
2. If minimum kept, reduce to 20-50 characters
3. Show character count but don't block submission for short descriptions
4. Update Zod validation schema

### AC3: Post-Creation Publish Prompt
1. After successful experience creation, show dialog/modal
2. Dialog asks: "Would you like to publish this experience now?"
3. Options: "Publish Now" and "Keep as Draft"
4. "Publish Now" updates status and redirects to experience list
5. "Keep as Draft" redirects to experience list with draft notice

### AC4: Fix Experience Preview
1. Investigate 404 "Missing required html tags" error
2. Preview should render experience detail page correctly
3. Preview opens in new tab or modal
4. Preview shows how experience will appear to visitors

### AC5: Fix Preview Loading State
1. Loading indicator shows when preview is triggered
2. Loading clears on success (preview opens)
3. Loading clears on error (with error message)
4. Button re-enables after preview attempt

### AC6: Fix Duplication Default Status
1. Duplicated experience is created with status `DRAFT`
2. Original experience status is NOT modified
3. Clear UI indication that duplicate is in draft

### AC7: Fix Duplication Data Integrity
1. Only the duplicated experience is modified, not original
2. Ensure unique slug generated for duplicate
3. Both experiences maintain independent state
4. Database transaction ensures atomicity

### AC8: Duplicate Time Slots
1. When duplicating experience, copy all associated time slots
2. Time slot IDs are new (not shared with original)
3. Availability and bookings start fresh for duplicate
4. Time slot duplication is part of same transaction

## Technical Investigation

### Preview 404 Issue

The error "Missing required html tags" suggests the preview route is not properly wrapped in RootLayout.

Check:
1. Preview route structure: `/dashboard/experiences/[id]/preview`
2. Whether preview has its own layout.tsx
3. If using route groups that exclude root layout

### Duplication Bug

Investigate if duplication modifies original due to:
1. Shared reference (object mutation)
2. Database query updating wrong record
3. Slug collision causing update instead of insert

```typescript
// Potential issue: Object mutation
const duplicate = original;  // Same reference!
duplicate.status = 'DRAFT';  // Mutates original too

// Fix: Deep clone
const duplicate = { ...original, id: undefined, status: 'DRAFT' };
```

### Duplication Fix

```typescript
// In duplicateExperience server action
export async function duplicateExperience(experienceId: string) {
  return db.$transaction(async (tx) => {
    // 1. Fetch original with time slots
    const original = await tx.experience.findUnique({
      where: { id: experienceId },
      include: { timeSlots: true, galleryImages: true },
    });

    if (!original) throw new Error('Experience not found');

    // 2. Generate new slug
    const newSlug = await generateUniqueSlug(original.title, original.wineryId);

    // 3. Create duplicate (deep clone, new ID, DRAFT status)
    const duplicate = await tx.experience.create({
      data: {
        ...original,
        id: undefined,          // New ID
        slug: newSlug,          // New slug
        status: 'DRAFT',        // Always draft
        createdAt: undefined,   // New timestamp
        updatedAt: undefined,
        timeSlots: undefined,   // Handle separately
        galleryImages: undefined,
      },
    });

    // 4. Copy time slots
    if (original.timeSlots.length > 0) {
      await tx.timeSlot.createMany({
        data: original.timeSlots.map(slot => ({
          ...slot,
          id: undefined,           // New ID
          experienceId: duplicate.id,  // Link to duplicate
        })),
      });
    }

    return duplicate;
  });
}
```
