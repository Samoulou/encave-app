## Acceptance Criteria

1. Error pages display messages in user's selected locale
2. Description fields show real-time character count (e.g., "150/5000")
3. Form fields show validation errors as user types (debounced)
4. Disabled form sections use proper `disabled` attributes, not CSS-only
5. Settings page has functional notification preferences form
6. Dashboard pages have proper meta titles
7. PWA icons exist in all required sizes
8. Failed images show fallback placeholder
9. Forms have proper autocomplete hints
10. All interactive text meets WCAG AA contrast (4.5:1)
11. Date picker is usable on mobile screens

### BUG-016: Real-time Validation

**Implementation:**
```typescript
// Use debounced validation
const [errors, setErrors] = useState({});

const validateField = useDebouncedCallback((name: string, value: string) => {
  const result = schema.safeParse({ [name]: value });
  if (!result.success) {
    setErrors(prev => ({ ...prev, [name]: result.error.issues[0].message }));
  } else {
    setErrors(prev => ({ ...prev, [name]: undefined }));
  }
}, 300);
```

### Character Counter Component

```typescript
// components/shared/CharacterCounter.tsx
interface CharacterCounterProps {
  current: number;
  min?: number;
  max: number;
}

export function CharacterCounter({ current, min = 0, max }: CharacterCounterProps) {
  const isBelowMin = current < min;
  const isNearMax = current > max * 0.9;
  const isOverMax = current > max;

  return (
    <span className={cn(
      'text-sm',
      isOverMax && 'text-red-600 font-medium',
      isNearMax && !isOverMax && 'text-amber-600',
      isBelowMin && 'text-gray-500',
      !isBelowMin && !isNearMax && 'text-gray-400'
    )}>
      {current.toLocaleString()}/{max.toLocaleString()}
      {min > 0 && current < min && ` (min ${min})`}
    </span>
  );
}
```
