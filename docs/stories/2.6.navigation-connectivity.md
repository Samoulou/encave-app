## Story

**As a** visitor or winemaker,
**I want** clear navigation paths to discover experiences and manage my offerings,
**so that** I can easily find what I'm looking for without knowing specific URLs.

## Acceptance Criteria

### Public Navigation

1. Header navigation includes "Experiences" link to `/experiences` (between "Wineries" and auth links)
2. "Experiences" link uses same styling as existing "Wineries" link
3. Active state styling when on `/experiences` or `/experiences/*` routes

### Dashboard Navigation

4. Dashboard sidebar component created with navigation links
5. Sidebar displays on all `/dashboard/*` routes
6. Sidebar links include:
   - "Experiences" → `/dashboard/experiences` (with icon)
   - "Winery Profile" → `/dashboard/winery/profile` (with icon)
7. Active state styling indicates current section
8. Sidebar collapses to icons on mobile (hamburger menu or icon-only mode)
9. Winemaker's winery name displayed at top of sidebar

### Homepage Discovery

10. Homepage includes discovery section with CTAs to `/experiences` and `/wineries` (replaces "Coming Soon" placeholder or adds above it)

## Rationale

This story addresses navigation gaps discovered during Epic 2 verification:

1. **Public Header Gap:** The `/experiences` page was created in Story 2.4 but no navigation link was added to the header. Users could only reach it via direct URL or breadcrumb from detail pages.

2. **Dashboard Sidebar Gap:** Stories 2.1-2.3 created dashboard pages for experience management, but no sidebar navigation exists. Winemakers cannot discover these pages without knowing URLs.

3. **Homepage Gap:** The homepage still shows a "Coming Soon" placeholder with no way to discover the implemented features.

These gaps were not explicitly covered in Stories 2.1-2.5 acceptance criteria, which focused on the pages themselves rather than navigation paths to reach them.
