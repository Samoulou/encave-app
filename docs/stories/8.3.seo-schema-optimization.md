# Story 8.3: SEO Schema & Optimization

## Status

Draft

## Story

**As a** search engine crawler,
**I want** complete structured data on all public pages,
**so that** EnCave appears with rich snippets in search results.

## Issues Addressed

| Issue ID | Severity | Description |
|----------|----------|-------------|
| SEO-001 | P1 | Winery pages sans schema.org |
| SEO-002 | P1 | Experience schema incomplet (startDate) |
| SEO-003 | P2 | Home page sans schema Organization |

## Acceptance Criteria

### AC1: Winery Schema.org (P1 - SEO-001)
1. Add `LocalBusiness` or `Winery` schema to `/wineries/[slug]` pages
2. Include: name, description, address, telephone, image, geo coordinates
3. Include: openingHours (if available), priceRange
4. Schema validates in Google Rich Results Test

### AC2: Experience Schema Completion (P1 - SEO-002)
1. Add `startDate` to Event schema (next available date)
2. Add `endDate` (startDate + duration)
3. Add `maximumAttendeeCapacity`
4. Add `remainingAttendeeCapacity` (dynamic)
5. Schema validates in Google Rich Results Test

### AC3: Home Page Schema (P2 - SEO-003)
1. Add `Organization` schema with EnCave details
2. Include: name, logo, url, description, areaServed
3. Include: sameAs (social links when available)

### AC4: Experiences Listing Schema (P2 - SEO-004)
1. Add `CollectionPage` or `ItemList` schema
2. Reference individual experiences
3. Include pagination info if applicable

### AC5: Breadcrumb Schema (P2 - SEO-005)
1. Add `BreadcrumbList` schema to breadcrumb component
2. Auto-generate from navigation path
3. Include on all pages with breadcrumbs

### AC6: Image Blur Placeholders (P2 - SEO-006)
1. Ensure all hero images use `placeholder="blur"`
2. Verify `blurDataURL` from `IMAGE_PLACEHOLDERS`
3. Audit all `next/image` usage for consistency

### Schema Examples

```typescript
// Winery LocalBusiness Schema
const winerySchema = {
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "@id": `https://encave.ch/wineries/${winery.slug}`,
  "name": winery.name,
  "description": winery.description,
  "image": winery.coverPhoto,
  "telephone": winery.phone,
  "address": {
    "@type": "PostalAddress",
    "streetAddress": winery.address,
    "addressLocality": winery.commune,
    "addressRegion": "Valais",
    "addressCountry": "CH"
  },
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": winery.latitude,
    "longitude": winery.longitude
  }
};

// Experience Event Schema (complete)
const eventSchema = {
  "@context": "https://schema.org",
  "@type": "Event",
  "name": experience.title,
  "description": experience.description,
  "image": experience.coverPhoto,
  "startDate": nextAvailableDate.toISOString(),
  "endDate": new Date(nextAvailableDate.getTime() + experience.duration * 60000).toISOString(),
  "location": {
    "@type": "Place",
    "name": experience.winery.name,
    "address": {
      "@type": "PostalAddress",
      "streetAddress": experience.winery.address,
      "addressLocality": experience.winery.commune,
      "addressRegion": "Valais",
      "addressCountry": "CH"
    }
  },
  "offers": {
    "@type": "Offer",
    "price": experience.price,
    "priceCurrency": "CHF",
    "availability": "https://schema.org/InStock",
    "validFrom": new Date().toISOString()
  },
  "organizer": {
    "@type": "Organization",
    "name": experience.winery.name,
    "url": `https://encave.ch/wineries/${experience.winery.slug}`
  },
  "maximumAttendeeCapacity": experience.maxCapacity,
  "remainingAttendeeCapacity": remainingCapacity
};

// Organization Schema (Home)
const organizationSchema = {
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "EnCave",
  "url": "https://encave.ch",
  "logo": "https://encave.ch/logo.png",
  "description": "Plateforme de réservation d'expériences viticoles en Valais",
  "areaServed": {
    "@type": "Place",
    "name": "Valais, Switzerland"
  }
};

// BreadcrumbList Schema
const breadcrumbSchema = {
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": items.map((item, index) => ({
    "@type": "ListItem",
    "position": index + 1,
    "name": item.label,
    "item": `https://encave.ch${item.href}`
  }))
};
```

### JSON-LD Script Component

```typescript
function JsonLd({ data }: { data: object }) {
  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(data) }}
    />
  );
}

// Usage in page
<JsonLd data={winerySchema} />
```

## Testing

### Testing Standards

- Use Google Rich Results Test for schema validation
- Use Lighthouse for SEO score verification
- Manual testing of structured data in search console

### Test Cases

1. **Winery Schema**
   - Test multiple winery pages
   - Verify all required fields present
   - Check Google Rich Results Test passes

2. **Experience Schema**
   - Test experience with available dates
   - Verify startDate/endDate calculated correctly
   - Check capacity fields accurate

3. **Breadcrumb Schema**
   - Test on nested pages (e.g., /wineries/domaine-x)
   - Verify hierarchy correct
   - Check clickable links

4. **Image Placeholders**
   - Test LCP improvement with blur placeholders
   - Verify no layout shift (CLS < 0.1)
