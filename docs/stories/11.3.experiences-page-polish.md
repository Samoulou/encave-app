# Story 11.3: Experiences Page Polish - Brownfield Addition

## User Story

As a **visitor browsing experiences**,
I want **the /expériences page to be fully translated, visually engaging, and functionally complete**,
So that **I can easily navigate, filter, and search for wine experiences in my preferred language**.

## Story Context

**Existing System Integration:**
- Integrates with: `/[locale]/(public)/experiences/` page components
- Technology: Next.js 15, next-intl, React, Tailwind CSS
- Follows pattern: Existing i18n patterns with `useTranslations` hook
- Touch points: `SearchFilters.tsx`, `SearchBar.tsx`, `ExperiencesPageClient.tsx`, layout components

## Problem Statement

User feedback identified 4 issues on the `/expériences` page:

1. **Navigation Gap**: No visible way to return to the home page
2. **Missing Translations**: Filter labels are hardcoded in English despite translations existing in `messages/*.json`
3. **Visual Engagement**: Page feels too white/sterile, lacks visual warmth
4. **Search Malfunction**: Search input field not functioning as expected

## Acceptance Criteria

### AC1: Navigation - Back to Home
- [ ] Add clear navigation link/button to return to home page
- [ ] Link should be visible and accessible on both mobile and desktop
- [ ] Uses existing translation key `nav.backToHome` or `common.buttons.goHome`

### AC2: Filter Translations (i18n)
- [ ] `SearchFilters.tsx` uses `useTranslations('search')` hook
- [ ] "Filters" label uses `t('filters')` → "Filtres"
- [ ] "Clear all" uses `t('clear')` or equivalent → "Effacer"
- [ ] "Experience Type" uses `t('experienceType')` → "Type d'expérience"
- [ ] Experience type options use `experience.types.*` translations:
  - TASTING → "Dégustation"
  - CELLAR_VISIT → "Visite de cave"
  - WORKSHOP → "Atelier"
  - VINEYARD_TOUR → "Visite du vignoble"
  - FOOD_PAIRING → "Accord mets-vins"
- [ ] "Location" uses `t('location')` → "Localisation"
- [ ] "All communes" uses `winery.allCommunes` → "Toutes les communes"
- [ ] "Price Range (CHF)" uses `t('priceRange')` → "Fourchette de prix (CHF)"
- [ ] "Min"/"Max" placeholders use `t('min')`/`t('max')`
- [ ] "Group Size (minimum)" uses `t('groupSize')` → "Taille du groupe (minimum)"
- [ ] "Any size" placeholder uses `t('anySize')` → "Toute taille"

### AC3: Visual Enhancement
- [ ] Add hero section or visual header with wine-related imagery
- [ ] Consider adding subtle background texture or gradient
- [ ] Maintain consistency with existing design system (burgundy, cream, slate colors)
- [ ] Ensure changes are responsive and don't impact performance

### AC4: Search Functionality Fix
- [ ] Investigate and fix search input functionality
- [ ] Verify search queries correctly filter experiences by title, description, winery name
- [ ] Ensure debounce behavior works correctly (300ms)
- [ ] Test search with French accented characters

### Integration Requirements
- [ ] Existing experience filtering continues to work unchanged
- [ ] New translations follow existing i18n pattern
- [ ] Integration with next-intl maintains current behavior
- [ ] No breaking changes to URL-based filter state

### Quality Requirements
- [ ] All translations verified in FR, EN, and DE
- [ ] Page loads without layout shift
- [ ] Lighthouse accessibility score maintained
- [ ] Mobile responsiveness preserved
