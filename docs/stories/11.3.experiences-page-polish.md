# Story 11.3: Experiences Page Polish - Brownfield Addition

## User Story

As a **visitor browsing experiences**,
I want **the /expériences page to be fully translated, visually engaging, and functionally complete**,
So that **I can easily navigate, filter, and search for wine experiences in my preferred language**.

## Story Context

**Existing System Integration:**
- Integrates with: `/[locale]/(public)/experiences/` page components
- Technology: Next.js 15, next-intl, React, Tailwind CSS
- Follows pattern: Existing i18n patterns with `useTranslations` hook
- Touch points: `SearchFilters.tsx`, `SearchBar.tsx`, `ExperiencesPageClient.tsx`, layout components

## Problem Statement

User feedback identified 4 issues on the `/expériences` page:

1. **Navigation Gap**: No visible way to return to the home page
2. **Missing Translations**: Filter labels are hardcoded in English despite translations existing in `messages/*.json`
3. **Visual Engagement**: Page feels too white/sterile, lacks visual warmth
4. **Search Malfunction**: Search input field not functioning as expected
