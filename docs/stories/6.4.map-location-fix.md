# Story 6.4: Fix Map Location Display

## Status

Done

## Story

**As a** visitor viewing an experience,
**I want** to see the exact location of the winery on the map,
**so that** I know exactly where to go for my booking.

## Bugs Addressed

| Bug ID | Severity | Description |
|--------|----------|-------------|
| BUG-007 | P1 | Map shows generic Valais region instead of specific winery location with pin |

## Acceptance Criteria

1. Map displays a pin at the exact winery location
2. Map is centered on the winery with appropriate zoom level
3. Winery name appears on pin tooltip/popup
4. "Get directions" link opens Google Maps with correct destination
5. Map works for all wineries with addresses
6. Fallback to region view if coordinates unavailable

## Technical Details

### Root Cause Analysis

**File:** `src/components/features/experience/LocationSection.tsx:48-55`

**Current Implementation (Broken):**
```typescript
// HARDCODED bounding box for entire Valais region
src={`https://www.openstreetmap.org/export/embed.html?bbox=${encodeURIComponent('7.0,46.0,8.0,46.5')}&layer=mapnik`}
```

**Problems:**
1. Bounding box is hardcoded - shows entire region, not specific location
2. No marker/pin on the map
3. Database schema lacks `latitude` and `longitude` fields

### Solution Options

**Option A: Geocoding Service (Recommended)**
1. Use geocoding API to convert address → coordinates
2. Cache coordinates in database for performance
3. Display map with dynamic center and marker

**Option B: Add Lat/Lng to Winery Schema**
1. Add `latitude` and `longitude` fields to Prisma schema
2. Require coordinates during winery registration
3. Use stored coordinates for map display

**Option C: Hybrid Approach (Best)**
1. Add optional `latitude`/`longitude` to schema
2. Auto-geocode from address if not provided
3. Store result for future use

**Geocoding Integration:**
```typescript
// Use a geocoding service (e.g., Nominatim, Google Geocoding)
async function geocodeAddress(address: string): Promise<{lat: number, lng: number} | null> {
  const response = await fetch(
    `https://nominatim.openstreetmap.org/search?format=json&q=${encodeURIComponent(address)}`
  );
  const data = await response.json();
  if (data[0]) {
    return { lat: parseFloat(data[0].lat), lng: parseFloat(data[0].lon) };
  }
  return null;
}
```

### OpenStreetMap Embed with Marker

```typescript
// Generate map URL with marker
function getMapUrl(lat: number, lng: number, zoom: number = 15): string {
  const bbox = {
    minLon: lng - 0.005,
    minLat: lat - 0.005,
    maxLon: lng + 0.005,
    maxLat: lat + 0.005,
  };

  return `https://www.openstreetmap.org/export/embed.html?` +
    `bbox=${bbox.minLon},${bbox.minLat},${bbox.maxLon},${bbox.maxLat}` +
    `&layer=mapnik&marker=${lat},${lng}`;
}
```
