# Story 12.7: Experience Availability Editor - Fix Non-Functional Controls

## Status

Ready for Review

## Assignee

@dev

## Story

**As a** winery owner creating an experience,
**I want** to be able to edit and delete availability time slots,
**so that** I can configure when my experience is available for booking.

## Problem Statement

The experience creation form has critical bugs in the Availability section:

1. **Edit Button Non-Functional**: The "Edit" button next to time slots does nothing - it has no onClick handler
2. **Time Slots Read-Only**: Users cannot modify the default time slots (09:00-11:30, 14:00-16:30)
3. **No Delete Option**: Users cannot remove time slots they don't want
4. **No Time Input**: There's no way to add custom start/end times when creating new slots

## Acceptance Criteria

### AC1: Edit Time Slots
1. Clicking "Edit" opens an inline editor or modal
2. User can modify start time and end time
3. Time validation: end time must be after start time
4. Changes update the slot immediately
5. Minimum slot duration: 30 minutes

### AC2: Delete Time Slots
1. Each time slot has a delete/remove button
2. Confirmation before deletion (or undo option)
3. At least one time slot must remain per schedule pattern
4. If last slot deleted, remove the entire schedule pattern

### AC3: Add Custom Time Slots
1. "Add time slot" button within each schedule pattern
2. Opens time picker for start and end time
3. Default to reasonable times (e.g., next hour)
4. Validates no overlapping slots in same schedule

### AC4: Delete Schedule Pattern
1. Each schedule pattern (day group) has a delete button
2. Removes entire pattern including all time slots
3. At least one schedule pattern should remain (warn if deleting last one)

## Implementation Hints

### Edit Handler Example

```typescript
const [editingTimeSlot, setEditingTimeSlot] = useState<{
  slotId: string;
  timeSlotIndex: number;
} | null>(null);

const handleEditTimeSlot = (slotId: string, timeSlotIndex: number) => {
  setEditingTimeSlot({ slotId, timeSlotIndex });
};

const handleSaveTimeSlot = (start: string, end: string) => {
  if (!editingTimeSlot) return;

  setAvailabilitySlots((prev) =>
    prev.map((slot) =>
      slot.id === editingTimeSlot.slotId
        ? {
            ...slot,
            timeSlots: slot.timeSlots.map((ts, idx) =>
              idx === editingTimeSlot.timeSlotIndex
                ? { start, end }
                : ts
            ),
          }
        : slot
    )
  );
  setEditingTimeSlot(null);
};
```

### Delete Time Slot Handler

```typescript
const handleDeleteTimeSlot = (slotId: string, timeSlotIndex: number) => {
  setAvailabilitySlots((prev) => {
    const slot = prev.find((s) => s.id === slotId);
    if (!slot) return prev;

    // If only one time slot, remove entire pattern
    if (slot.timeSlots.length === 1) {
      return prev.filter((s) => s.id !== slotId);
    }

    // Otherwise, just remove the time slot
    return prev.map((s) =>
      s.id === slotId
        ? { ...s, timeSlots: s.timeSlots.filter((_, idx) => idx !== timeSlotIndex) }
        : s
    );
  });
};
```

### Time Validation

```typescript
const isValidTimeSlot = (start: string, end: string): boolean => {
  const startMinutes = timeToMinutes(start);
  const endMinutes = timeToMinutes(end);
  return endMinutes > startMinutes && (endMinutes - startMinutes) >= 30;
};

const timeToMinutes = (time: string): number => {
  const [hours, minutes] = time.split(':').map(Number);
  return hours * 60 + minutes;
};
```
