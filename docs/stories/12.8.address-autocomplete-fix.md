## Story

**As a** winery owner creating an experience,
**I want** the address autocomplete to work reliably,
**so that** I can easily set the location for my experience.

## Problem Statement

The address autocomplete feature in the experience creation form is not functioning correctly. Users report that:

1. Typing in the address field doesn't show suggestions
2. The autocomplete dropdown never appears
3. The feature appears broken/non-functional

## Root Cause Analysis

After code review of `src/components/features/experience/AddressAutocomplete.tsx`:

### Issue 1: CORS and Browser Restrictions

The component makes direct client-side fetch calls to the Nominatim API:

```typescript
const response = await fetch(
  `https://nominatim.openstreetmap.org/search?...`,
  {
    headers: {
      'User-Agent': 'EnCave/1.0 (https://encave.ch)',
    },
  }
);
```

**Problems:**
- Browsers block custom `User-Agent` headers in fetch requests (forbidden header)
- Nominatim requires a valid User-Agent to identify the application
- Without proper User-Agent, requests may be rate-limited or blocked

### Issue 2: No Error Handling Visibility

Errors are caught but only logged to console:

```typescript
} catch (error) {
  console.error('Address search error:', error);
  setSuggestions([]);
}
```

No user feedback when the API fails.

### Issue 3: Rate Limiting

Nominatim has strict usage policies:
- Max 1 request per second
- Requires identifying User-Agent
- May block heavy usage from single IPs

## Proposed Solution

### Option A: Server-Side Proxy (Recommended)

Create a Next.js API route to proxy requests to Nominatim:

```
/api/geocode/search?q=...
```

**Benefits:**
- Proper User-Agent can be set server-side
- Can implement caching to reduce API calls
- Can add rate limiting protection
- Better error handling
- Can switch geocoding providers without client changes

### Option B: Use Google Places API

Replace Nominatim with Google Places Autocomplete:
- More reliable
- Better Swiss address coverage
- Costs money (but free tier available)

### Option C: Use Mapbox Geocoding

Alternative commercial option:
- Good reliability
- Reasonable free tier
- Good Swiss coverage

**Recommendation**: Option A (Server-Side Proxy) - maintains free usage, fixes the core issue.

### API Route Implementation

```typescript
// src/app/api/geocode/search/route.ts
import { NextRequest, NextResponse } from 'next/server';

const NOMINATIM_BASE_URL = 'https://nominatim.openstreetmap.org/search';
const CACHE_TTL = 5 * 60 * 1000; // 5 minutes

// Simple in-memory cache
const cache = new Map<string, { data: unknown; timestamp: number }>();

export async function GET(request: NextRequest) {
  const searchParams = request.nextUrl.searchParams;
  const query = searchParams.get('q');

  if (!query || query.length < 3) {
    return NextResponse.json({ error: 'Query too short' }, { status: 400 });
  }

  // Check cache
  const cacheKey = query.toLowerCase();
  const cached = cache.get(cacheKey);
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    return NextResponse.json(cached.data);
  }

  try {
    // Add Switzerland context
    const searchQuery = query.includes('Switzerland')
      ? query
      : `${query}, Valais, Switzerland`;

    const url = new URL(NOMINATIM_BASE_URL);
    url.searchParams.set('q', searchQuery);
    url.searchParams.set('format', 'json');
    url.searchParams.set('limit', '5');
    url.searchParams.set('addressdetails', '1');
    url.searchParams.set('countrycodes', 'ch');

    const response = await fetch(url.toString(), {
      headers: {
        'User-Agent': 'EnCave/1.0 (https://encave.ch; contact@encave.ch)',
        'Accept': 'application/json',
      },
    });

    if (!response.ok) {
      throw new Error(`Nominatim error: ${response.status}`);
    }

    const data = await response.json();

    // Cache the result
    cache.set(cacheKey, { data, timestamp: Date.now() });

    return NextResponse.json(data);
  } catch (error) {
    console.error('Geocode search error:', error);
    return NextResponse.json(
      { error: 'Failed to search addresses' },
      { status: 500 }
    );
  }
}
```

### Updated AddressAutocomplete

```typescript
// Key changes to AddressAutocomplete.tsx

const searchAddress = useCallback(async (searchQuery: string) => {
  if (searchQuery.length < 3) {
    setSuggestions([]);
    return;
  }

  setIsLoading(true);
  setError(null);

  try {
    // Use our proxy instead of direct Nominatim call
    const response = await fetch(
      `/api/geocode/search?q=${encodeURIComponent(searchQuery)}`
    );

    if (!response.ok) {
      throw new Error('Search failed');
    }

    const data = await response.json();

    if (Array.isArray(data)) {
      setSuggestions(data);
      setIsOpen(data.length > 0);
    } else {
      setSuggestions([]);
      setError('No results found');
    }
  } catch (error) {
    console.error('Address search error:', error);
    setSuggestions([]);
    setError('Unable to search addresses. Please try again.');
  } finally {
    setIsLoading(false);
  }
}, []);
```
