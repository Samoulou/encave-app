# Story 11.2: SEO Landing Pages - Oenotourisme Valais

## Status

Ready for Review

## Story

**As a** potential visitor searching for wine experiences in Valais,
**I want** to find EnCave through targeted search queries like "dégustation vin valais",
**so that** I can discover and book wine tasting experiences in the region.

## Context

EnCave has excellent technical SEO infrastructure (sitemap, Schema.org, hreflang, metadata) but lacks **content-rich landing pages** targeting specific search intents. Currently, generic listing pages (`/experiences`, `/wineries`) don't rank for long-tail keywords like:

- "dégustation vin valais"
- "oenotourisme valais"
- "cave à visiter sion"
- "route des vins valais"

### Business Value

- **Organic traffic acquisition** - Capture high-intent searches
- **Reduced marketing costs** - SEO vs paid advertising
- **Authority building** - Position EnCave as the reference for Valais wine tourism
- **Conversion path** - Guide visitors from discovery to booking

### Technical Feasibility

Architecture analysis confirms **EASY** implementation:
- Routing ready (`src/app/[locale]/(public)/`)
- Template exists (About page pattern)
- i18n infrastructure complete (FR/DE/EN)
- SEO components available (JsonLd, generateMetadata)

### FAQ Schema Pattern

```tsx
// src/components/seo/FaqSchema.tsx
interface FaqItem {
  question: string;
  answer: string;
}

export function FaqSchema({ items }: { items: FaqItem[] }) {
  const schema = {
    '@context': 'https://schema.org',
    '@type': 'FAQPage',
    mainEntity: items.map(item => ({
      '@type': 'Question',
      name: item.question,
      acceptedAnswer: {
        '@type': 'Answer',
        text: item.answer,
      },
    })),
  };

  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(schema) }}
    />
  );
}
```

### Query Pattern for Featured Content

```typescript
// Fetch featured experiences for landing page
export async function getFeaturedExperiences(limit: number = 6) {
  return prisma.experience.findMany({
    where: {
      status: 'PUBLISHED',
      winery: { verified: true },
    },
    include: {
      winery: true,
      images: { take: 1 },
    },
    orderBy: { createdAt: 'desc' },
    take: limit,
  });
}
```
