# Story 8.6: Mobile Responsiveness

## Status

Done

## Story

**As a** mobile user,
**I want** the homepage and navigation to be fully responsive,
**so that** I can browse and navigate EnCave on any device.

## Issues Identified

| Issue ID | Severity | Component | Description |
|----------|----------|-----------|-------------|
| MOB-001 | P1 | Header | No mobile navigation menu - nav links hidden on mobile with no alternative |
| MOB-002 | P2 | Homepage | Typography uses fixed display sizes that overflow on mobile |
| MOB-003 | P3 | Homepage | Card padding not responsive per design system |
| MOB-004 | P2 | Header | Auth buttons may overflow on small screens |

## Acceptance Criteria

### AC1: Mobile Navigation Menu (P1 - MOB-001)
1. Hamburger menu icon visible on screens < md breakpoint
2. Mobile menu drawer opens on hamburger click
3. All navigation links accessible in mobile menu
4. Menu closes on link click or outside tap
5. Smooth open/close animation respecting reduced-motion preference
6. Focus trap when menu is open for accessibility

### AC2: Responsive Typography (P2 - MOB-002)
1. Hero title scales: `text-3xl sm:text-4xl md:text-display-lg`
2. Section headers scale: `text-2xl sm:text-display-md`
3. No horizontal overflow on any screen size
4. Text remains readable on smallest supported screens (320px)

### AC3: Responsive Card Layout (P3 - MOB-003)
1. Card padding follows design system: `p-6 sm:p-8`
2. Card content remains accessible on mobile
3. Touch targets meet 44x44px minimum

### AC4: Header Auth Section (P2 - MOB-004)
1. Auth buttons stack or collapse appropriately on mobile
2. UserMenu accessible on all screen sizes
3. LocaleSwitcher remains functional on mobile

### Technical Implementation

```typescript
// MobileNav.tsx - Client component for interactivity
'use client';

import { useState } from 'react';
import Link from 'next/link';
import { Menu, X, Wine } from 'lucide-react';
import { useTranslations } from 'next-intl';
import { Button } from '@/components/ui/button';
import {
  Sheet,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from '@/components/ui/sheet';
import { LocaleSwitcher } from '@/components/shared/LocaleSwitcher';

interface MobileNavProps {
  isAuthenticated: boolean;
  userName?: string | null;
  userRole?: string | null;
}

export function MobileNav({ isAuthenticated, userName, userRole }: MobileNavProps) {
  const [open, setOpen] = useState(false);
  const t = useTranslations('nav');

  const closeMenu = () => setOpen(false);

  return (
    <Sheet open={open} onOpenChange={setOpen}>
      <SheetTrigger asChild>
        <Button
          variant="ghost"
          size="icon"
          className="md:hidden"
          aria-label={t('openMenu')}
        >
          <Menu className="h-6 w-6" />
        </Button>
      </SheetTrigger>
      <SheetContent side="right" className="w-[300px] sm:w-[350px]">
        <SheetHeader>
          <SheetTitle className="flex items-center gap-2">
            <Wine className="h-5 w-5 text-burgundy-600" />
            <span className="font-display text-burgundy-800">EnCave</span>
          </SheetTitle>
        </SheetHeader>
        <nav className="flex flex-col gap-4 mt-8">
          <Link
            href="/wineries"
            onClick={closeMenu}
            className="text-lg font-medium text-slate-700 hover:text-burgundy-600 transition-colors py-2"
          >
            {t('wineries')}
          </Link>
          <Link
            href="/experiences"
            onClick={closeMenu}
            className="text-lg font-medium text-slate-700 hover:text-burgundy-600 transition-colors py-2"
          >
            {t('experiences')}
          </Link>
          {userRole === 'ADMIN' && (
            <Link
              href="/admin"
              onClick={closeMenu}
              className="text-lg font-medium text-slate-700 hover:text-burgundy-600 transition-colors py-2"
            >
              {t('admin')}
            </Link>
          )}
          {userRole === 'WINEMAKER' && (
            <Link
              href="/dashboard"
              onClick={closeMenu}
              className="text-lg font-medium text-slate-700 hover:text-burgundy-600 transition-colors py-2"
            >
              {t('dashboard')}
            </Link>
          )}

          <div className="border-t border-stone-200 my-4" />

          {isAuthenticated ? (
            <>
              <p className="text-sm text-slate-500">{t('signedInAs', { name: userName })}</p>
              <Link
                href="/api/auth/signout"
                onClick={closeMenu}
                className="text-lg font-medium text-slate-700 hover:text-burgundy-600 transition-colors py-2"
              >
                {t('signOut')}
              </Link>
            </>
          ) : (
            <div className="flex flex-col gap-3">
              <Button variant="outline" asChild onClick={closeMenu}>
                <Link href="/login">{t('signIn')}</Link>
              </Button>
              <Button asChild onClick={closeMenu}>
                <Link href="/register">{t('getStarted')}</Link>
              </Button>
            </div>
          )}

          <div className="border-t border-stone-200 my-4" />
          <div className="flex items-center gap-2">
            <span className="text-sm text-slate-500">{t('language')}</span>
            <LocaleSwitcher />
          </div>
        </nav>
      </SheetContent>
    </Sheet>
  );
}
```

### Responsive Typography Classes

```tsx
// Before (fixed sizes)
<h1 className="font-display text-display-lg text-burgundy-800 mb-4">

// After (responsive)
<h1 className="font-display text-3xl sm:text-4xl md:text-display-lg text-burgundy-800 mb-4">
```

### Breakpoints Reference

| Breakpoint | Width | Usage |
|------------|-------|-------|
| default | 0-639px | Mobile phones |
| sm | 640px+ | Large phones, small tablets |
| md | 768px+ | Tablets, show desktop nav |
| lg | 1024px+ | Desktop |
| xl | 1280px+ | Large desktop |
