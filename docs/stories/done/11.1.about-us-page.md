# Story 11.1: About Us Page - Valais Wine Heritage

## Status

Done

## Story

**As a** visitor to EnCave,
**I want** to learn about the creator and the passion behind the platform,
**so that** I understand the authenticity and connection to Valais wine heritage.

## Context

EnCave is built by Samuel, a passionate Valaisan who wants to showcase the exceptional wines of his homeland. The About page serves to:
- Share the story and passion behind EnCave
- Celebrate Valais wine heritage (terroir, quality, unique grape varieties)
- Provide a personal touch and contact information
- Build trust with visitors through authentic storytelling

## Acceptance Criteria

### AC1: About Page Creation
1. Create `/about` route accessible in all locales (`/fr/about`, `/en/about`, `/de/about`)
2. Page displays hero section with compelling headline
3. Page includes sections for: mission, Valais heritage, and contact
4. Responsive design following existing patterns
5. Page has proper SEO metadata

### AC2: Header Navigation Integration
1. Add "About" link in main navigation (desktop)
2. Add "About" link in mobile navigation drawer
3. Link positioned after "Experiences" in nav order
4. Active state styling when on About page

### AC3: Trilingual Content
1. French content as primary (original text)
2. English translation
3. German translation
4. All translations maintain emotional impact and authenticity

### AC4: Design & Styling
1. Use existing typography (font-display for headings)
2. Use burgundy color palette consistent with brand
3. Include subtle wine-related visual elements
4. Card-based layout for content sections
5. Contact section with email link

### Page Component Pattern

```tsx
import { getTranslations } from 'next-intl/server';
import { Card, CardContent } from '@/components/ui/card';

export async function generateMetadata({ params: { locale } }) {
  const t = await getTranslations({ locale, namespace: 'about' });
  return {
    title: t('metadata.title'),
    description: t('metadata.description'),
  };
}
```
