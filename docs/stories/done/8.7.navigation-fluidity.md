# Story 8.7: Navigation Fluidity & Perceived Performance

## Status

Done

## Story

**As a** user navigating the application,
**I want** instant visual feedback when I click any link or trigger any action,
**so that** the application feels responsive and modern, even when data loading takes time.

## Problem Statement

Users experience a 1-2 second delay between clicking a navigation element and seeing any response. During this time:
- No visual change occurs
- Users are unsure if their click registered
- The app feels slow/frozen even though it's working
- Multiple frustrated clicks may occur

**Root Cause:** The application waits for server data before updating the UI instead of updating the UI optimistically and streaming data progressively.

## Issues Addressed

| Issue ID | Severity | Description |
|----------|----------|-------------|
| UX-001 | P1 | Navigation feels laggy - no instant feedback on route changes |
| UX-002 | P1 | Filter/search interactions block UI during server updates |
| UX-003 | P2 | Missing route prefetching causes perceived slowness |
| UX-004 | P2 | Single large Suspense boundaries instead of granular streaming |

## Acceptance Criteria

### AC1: Instant Navigation Feedback with useTransition
1. All programmatic navigation uses `useTransition` hook
2. UI updates immediately on click (visual feedback < 50ms)
3. Loading indicators show during pending state
4. Navigation remains non-blocking

### AC2: Optimistic UI Updates with useOptimistic
1. Filter changes update UI instantly before server confirms
2. Search input shows results optimistically
3. Sort changes reflect immediately in UI
4. Pagination navigation feels instant

### AC3: Route Prefetching
1. Critical navigation links prefetch on hover/focus
2. Dashboard navigation prefetches likely destinations
3. Pagination links prefetch next/previous pages
4. `next/link` prefetch enabled for primary navigation

### AC4: Granular Suspense Boundaries
1. Summary cards stream independently from data tables
2. Filters/search load independently from results
3. Related content sections have separate boundaries
4. Each section shows its own skeleton, not full-page skeleton

### AC5: Debounced Search with Stale-While-Revalidate
1. Search input debounced at 300ms
2. Previous results remain visible during update (opacity reduced)
3. New results fade in smoothly
4. No flash of empty content during search

## Technical Architecture

### Pattern 1: Navigation with useTransition

```typescript
// src/hooks/useNavigateWithTransition.ts
'use client';

import { useRouter } from 'next/navigation';
import { useTransition } from 'react';

export function useNavigateWithTransition() {
  const router = useRouter();
  const [isPending, startTransition] = useTransition();

  const navigate = (href: string, options?: { scroll?: boolean }) => {
    startTransition(() => {
      router.push(href, options);
    });
  };

  const prefetch = (href: string) => {
    router.prefetch(href);
  };

  return { navigate, prefetch, isPending };
}
```

### Pattern 2: Optimistic Filters

```typescript
// Usage in ExperiencesPageClient.tsx
'use client';

import { useOptimistic, useTransition } from 'react';

export function ExperiencesPageClient({ initialFilters, experiences }) {
  const router = useRouter();
  const [isPending, startTransition] = useTransition();
  const [optimisticFilters, setOptimisticFilters] = useOptimistic(initialFilters);

  const updateFilter = (key: string, value: string) => {
    // 1. Update UI IMMEDIATELY
    setOptimisticFilters((prev) => ({ ...prev, [key]: value }));

    // 2. Sync with server in background
    startTransition(() => {
      const params = new URLSearchParams(window.location.search);
      params.set(key, value);
      router.push(`?${params.toString()}`, { scroll: false });
    });
  };

  return (
    <div className={isPending ? 'opacity-70 transition-opacity' : ''}>
      <FilterBar
        filters={optimisticFilters}
        onChange={updateFilter}
        isPending={isPending}
      />
      <ExperienceGrid experiences={experiences} />
    </div>
  );
}
```

### Pattern 3: Prefetching Navigation

```typescript
// src/components/layout/NavLink.tsx
'use client';

import Link from 'next/link';
import { useRouter } from 'next/navigation';
import { useCallback } from 'react';

interface NavLinkProps {
  href: string;
  children: React.ReactNode;
  prefetch?: boolean;
}

export function NavLink({ href, children, prefetch = true }: NavLinkProps) {
  const router = useRouter();

  const handleMouseEnter = useCallback(() => {
    if (prefetch) {
      router.prefetch(href);
    }
  }, [href, prefetch, router]);

  return (
    <Link
      href={href}
      prefetch={prefetch}
      onMouseEnter={handleMouseEnter}
      onFocus={handleMouseEnter}
    >
      {children}
    </Link>
  );
}
```

### Pattern 4: Granular Suspense Boundaries

```tsx
// src/app/[locale]/(protected)/dashboard/bookings/page.tsx
import { Suspense } from 'react';

export default async function BookingsPage({ searchParams }) {
  const params = await searchParams;

  return (
    <div className="space-y-6">
      {/* Header renders instantly */}
      <PageHeader title="Bookings" />

      {/* Stats stream first (usually faster query) */}
      <Suspense fallback={<StatsSkeleton />}>
        <BookingStats />
      </Suspense>

      {/* Filters render with cached data or optimistically */}
      <Suspense fallback={<FiltersSkeleton />}>
        <BookingFilters params={params} />
      </Suspense>

      {/* Table streams separately (heavier query) */}
      <Suspense fallback={<TableSkeleton />}>
        <BookingsTable params={params} />
      </Suspense>
    </div>
  );
}
```

### Pattern 5: Debounced Search

```typescript
// src/hooks/useDebouncedSearch.ts
'use client';

import { useState, useEffect, useTransition, useOptimistic } from 'react';
import { useRouter, useSearchParams } from 'next/navigation';

export function useDebouncedSearch(delay = 300) {
  const router = useRouter();
  const searchParams = useSearchParams();
  const [isPending, startTransition] = useTransition();

  const currentQuery = searchParams.get('q') || '';
  const [inputValue, setInputValue] = useState(currentQuery);
  const [optimisticQuery, setOptimisticQuery] = useOptimistic(currentQuery);

  useEffect(() => {
    const timer = setTimeout(() => {
      if (inputValue !== currentQuery) {
        setOptimisticQuery(inputValue);
        startTransition(() => {
          const params = new URLSearchParams(searchParams);
          if (inputValue) {
            params.set('q', inputValue);
          } else {
            params.delete('q');
          }
          router.push(`?${params.toString()}`, { scroll: false });
        });
      }
    }, delay);

    return () => clearTimeout(timer);
  }, [inputValue, delay]);

  return {
    inputValue,
    setInputValue,
    optimisticQuery,
    isPending,
    isStale: inputValue !== currentQuery,
  };
}
```
