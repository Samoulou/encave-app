## Technical Details

### BUG-008: Slow Navigation

**Root Causes Identified:**

1. **Dynamic imports in useEffect:**
```typescript
// BAD - loads module inside effect
useEffect(() => {
  import('@/server/actions/booking').then(({ checkAvailability }) => {
    // ...
  });
}, []);

// GOOD - import at top level
import { checkAvailability } from '@/server/actions/booking';
```

2. **Missing React.memo on expensive components:**
- `BookingsTable` - renders many rows
- `TransactionTable` - renders many rows
- `SearchResults` - renders experience cards

3. **Client-side fetching in checkout:**
```typescript
// BAD - fetches on client
useEffect(() => {
  getExperienceForBooking(slug).then((result) => { ... });
}, [slug]);

// GOOD - fetch on server
const experience = await getExperienceForBooking(slug);
```

4. **useQueryState with shallow: false:**
```typescript
// Causes full re-renders
useQueryStates({...}, { shallow: false });

// Better - use shallow: true where possible
useQueryStates({...}, { shallow: true });
```

5. **No component code splitting:**
- Large components loaded eagerly
- Could use `next/dynamic` for heavy components

### BUG-018: Images Without Blur Placeholder

**Files:** Multiple components using Next.js Image

**Problem:**
```typescript
// Current - no placeholder
<Image src={url} alt={alt} fill />

// Fixed - with blur placeholder
<Image
  src={url}
  alt={alt}
  fill
  placeholder="blur"
  blurDataURL="data:image/jpeg;base64,/9j/4AAQ..."
/>
```

**Solutions:**
1. Generate blur data URLs at build time
2. Use `plaiceholder` library for automatic generation
3. For remote images, use a small base64 placeholder

### Pagination Component

```typescript
// components/shared/Pagination.tsx
interface PaginationProps {
  currentPage: number;
  totalPages: number;
  onPageChange: (page: number) => void;
  pageSize?: number;
  onPageSizeChange?: (size: number) => void;
}

export function Pagination({
  currentPage,
  totalPages,
  onPageChange,
  pageSize = 20,
  onPageSizeChange,
}: PaginationProps) {
  return (
    <div className="flex items-center justify-between">
      <div className="flex items-center gap-2">
        <Button
          onClick={() => onPageChange(currentPage - 1)}
          disabled={currentPage === 1}
        >
          Previous
        </Button>
        <span>Page {currentPage} of {totalPages}</span>
        <Button
          onClick={() => onPageChange(currentPage + 1)}
          disabled={currentPage === totalPages}
        >
          Next
        </Button>
      </div>
      {onPageSizeChange && (
        <Select value={pageSize} onChange={onPageSizeChange}>
          <option value={10}>10 per page</option>
          <option value={20}>20 per page</option>
          <option value={50}>50 per page</option>
        </Select>
      )}
    </div>
  );
}
```

### Image Blur Placeholder

```typescript
// Option 1: Static placeholder
const shimmer = (w: number, h: number) => `
<svg width="${w}" height="${h}" xmlns="http://www.w3.org/2000/svg">
  <rect width="${w}" height="${h}" fill="#e2d6d9"/>
</svg>`;

const toBase64 = (str: string) =>
  typeof window === 'undefined'
    ? Buffer.from(str).toString('base64')
    : window.btoa(str);

// Usage
<Image
  src={url}
  alt={alt}
  fill
  placeholder="blur"
  blurDataURL={`data:image/svg+xml;base64,${toBase64(shimmer(700, 475))}`}
/>
```
