1. Dashboard summary cards display correct counts for Today, This Week, This Month

## Technical Details

### BUG-004: Dashboard Cards Not Updating

**Files:**
- `src/server/queries/booking.queries.ts:151-160`
- `src/components/features/booking/dashboard/BookingSummaryCards.tsx`

**Problem:**
Date type mismatch between database (`DateTime @db.Date`) and JavaScript queries:

```typescript
// Database stores date-only (no time component)
// Query uses full DateTime with time
const todayStart = startOfDay(now);  // 2026-01-12T00:00:00.000Z
const todayEnd = endOfDay(now);      // 2026-01-12T23:59:59.999Z

// But database has: 2026-01-12 (no time)
// Comparison may fail at timezone boundaries
```

**Fix Required:**
1. Normalize dates to UTC midnight before comparison
2. Use date-only string comparison (`yyyy-MM-dd`) instead of DateTime
3. Ensure server timezone matches database timezone
4. Add explicit timezone handling in queries

### BUG-005: Calendar Events Not Displaying

**Files:**
- `src/server/queries/calendar.queries.ts:108-149`
- `src/components/features/booking/calendar/CalendarView.tsx:82-83`

**Problem:**
Same date type mismatch. Calendar groups by `yyyy-MM-dd` string but database dates may not match due to timezone offset.

```typescript
// Calendar expects key like: "2026-01-12"
const dateKey = format(date, 'yyyy-MM-dd');
return calendarData.get(dateKey);  // Returns undefined if key doesn't match
```

**Fix Required:**
1. Ensure consistent date formatting in calendar query
2. Use UTC-based date keys
3. Add fallback for timezone edge cases
4. Log mismatches for debugging

### BUG-006: Earnings Not Displaying

**Files:**
- `src/server/queries/earnings.queries.ts`
- `src/components/features/earnings/EarningsSummaryCards.tsx`
- `src/components/features/earnings/TransactionTable.tsx`

**Problem:**
Transaction status uses simplistic 7-day rule:

```typescript
const daysSinceExperience = differenceInDays(new Date(), bookingDate);
return daysSinceExperience >= 7 ? 'paid' : 'pending';
```

If all experiences are recent (<7 days), everything shows as "pending".

**Fix Required:**
1. Use actual Stripe payout status if available
2. For estimation, use more realistic logic:
   - Experience completed (date passed) + 2 business days = "processing"
   - Experience completed + 5 business days = "paid"
3. Add "completed" intermediate status
4. Show estimated payout date based on Stripe schedule

### BUG-021: Calendar Not Reactive

**Files:**
- `src/app/[locale]/(protected)/dashboard/bookings/CalendarViewWrapper.tsx:64-66`

**Problem:**
```typescript
const handleRefresh = useCallback(() => {
  router.refresh();  // Full page refresh, not data refresh
}, [router]);
```

**Fix Required:**
1. Implement data-only refresh using `revalidatePath` or SWR
2. Add automatic refresh on tab focus
3. Consider polling every 60s for real-time feel
4. Use optimistic updates when possible
