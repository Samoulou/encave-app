# Story 12.6: Booking Display & Email Link Fixes

## Status

Draft

## Story

**As a** visitor who has made a booking,
**I want** confirmation emails with working links and clear pricing display,
**so that** I can access my booking details and understand what I'm paying for.

## Problem Statement

User feedback identified 2 issues with the booking/email experience:

1. **Email Link Broken**: The "View my reservation" button in confirmation emails links to a non-functional URL: `https://encave-app.vercel.app/fr/bookings/EC-FG75YC9Y`
2. **Price Display Confusing**: Booking page shows "Prix total CHF 65.00 x 1 1 personne" which is redundant and unclear

## Bugs Addressed

| Bug ID | Severity | Description |
|--------|----------|-------------|
| BUG-061 | P1 | Email "View my reservation" link broken (404 or inaccessible) |
| BUG-062 | P2 | Price display format "CHF 65.00 x 1 1 personne" is confusing |

## Acceptance Criteria

### AC1: Fix Email Reservation Link
1. Email "View my reservation" button links to functional page
2. Link works for both authenticated and unauthenticated users
3. Page displays booking details:
   - Experience name
   - Date and time
   - Number of guests
   - Total price
   - Booking reference (EC-XXXXXX)
   - Winery contact information
4. Page is accessible without login (public booking confirmation)
5. Link includes locale prefix

### AC2: Booking Confirmation Page
1. Create/fix `/bookings/[reference]` route
2. Page fetches booking by reference code
3. Page shows confirmation status
4. Page provides options: Add to Calendar, Print, Contact Winery
5. Page is responsive (mobile-friendly)

### AC3: Fix Price Display Format
1. Price displays as "CHF 65.00 x {guests} = CHF {total}"
2. Or simplified: "CHF {total} ({guests} {person/people})"
3. Handle singular/plural correctly ("personne" vs "personnes")
4. Format consistent across:
   - Booking widget
   - Checkout page
   - Confirmation email
   - Booking confirmation page

### AC4: Email Template Verification
1. Verify email template uses correct URL format
2. Ensure booking reference is included in link
3. Test email rendering in major clients (Gmail, Outlook, Apple Mail)

## Dev Notes

### Booking Confirmation Page

```tsx
// src/app/[locale]/(public)/bookings/[reference]/page.tsx
import { getBookingByReference } from '@/server/queries/booking.queries';
import { notFound } from 'next/navigation';

interface Props {
  params: Promise<{ locale: string; reference: string }>;
}

export default async function BookingConfirmationPage({ params }: Props) {
  const { reference, locale } = await params;

  const booking = await getBookingByReference(reference);

  if (!booking) {
    notFound();
  }

  return (
    <div className="container mx-auto py-8 px-4">
      <div className="max-w-2xl mx-auto">
        <div className="bg-white rounded-lg shadow-lg p-6">
          <div className="text-center mb-6">
            <CheckCircle className="h-16 w-16 text-green-500 mx-auto" />
            <h1 className="text-2xl font-bold mt-4">
              {t('booking.confirmed')}
            </h1>
            <p className="text-stone-600">
              {t('booking.reference')}: {booking.reference}
            </p>
          </div>

          <div className="space-y-4">
            <div>
              <h2 className="font-semibold">{booking.experience.title}</h2>
              <p>{format(booking.date, 'PPP', { locale: dateLocale })}</p>
              <p>{booking.time}</p>
            </div>

            <div>
              <p>{booking.guests} {t('booking.guests', { count: booking.guests })}</p>
              <p className="text-lg font-semibold">
                {t('booking.total')}: CHF {formatPrice(booking.totalPrice)}
              </p>
            </div>

            <div className="border-t pt-4">
              <h3 className="font-semibold">{t('booking.winery')}</h3>
              <p>{booking.experience.winery.name}</p>
              <p>{booking.experience.winery.email}</p>
              <p>{booking.experience.winery.phone}</p>
            </div>
          </div>

          <div className="mt-6 flex gap-4">
            <Button onClick={addToCalendar}>
              <Calendar className="mr-2 h-4 w-4" />
              {t('booking.addToCalendar')}
            </Button>
            <Button variant="outline" onClick={() => window.print()}>
              <Printer className="mr-2 h-4 w-4" />
              {t('booking.print')}
            </Button>
          </div>
        </div>
      </div>
    </div>
  );
}
```

### Price Format Fix

```tsx
// Using ICU Message Format for plurals

  "booking": {

    "priceSummary": "{count, plural, one {# personne} other {# personnes}} × CHF {unitPrice} = CHF {total}"
  }
}

// Usage
const t = useTranslations('booking');
```

### Add to Calendar (.ics)

```typescript
const generateICSFile = (booking: Booking) => {
  const icsContent = `BEGIN:VCALENDAR
VERSION:2.0
BEGIN:VEVENT
DTSTART:${formatICSDate(booking.date, booking.time)}
DTEND:${formatICSDate(addMinutes(booking.date, booking.experience.duration), booking.time)}
SUMMARY:${booking.experience.title}
LOCATION:${booking.experience.winery.address}
DESCRIPTION:Booking reference: ${booking.reference}
END:VEVENT
END:VCALENDAR`;

  const blob = new Blob([icsContent], { type: 'text/calendar' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `encave-${booking.reference}.ics`;
  a.click();
};
```
