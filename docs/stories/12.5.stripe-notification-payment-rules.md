# Story 12.5: Stripe Setup Notification & Payment Status Documentation

## Status

Draft

## Story

**As a** winemaker setting up my account,
**I want** clear notification when Stripe payment integration is incomplete,
**so that** I understand I need to complete setup before accepting bookings.

## Problem Statement

User feedback identified 2 issues related to payment configuration:

1. **Missing Stripe Setup Alert**: When a winemaker hasn't completed Stripe Connect onboarding, there's no visible notification in the dashboard explaining that payments won't work
2. **Payment Status Rules Unclear**: Users don't understand what "pending" payment status means and when payments become "paid"

## Bugs/Improvements Addressed

| Bug ID | Severity | Description |
|--------|----------|-------------|
| BUG-059 | P1 | No notification when Stripe Connect not configured |
| BUG-060 | P3 | Payment "pending" status rules need documentation |

### AC1: Stripe Setup Notification Banner

5. Banner disappears automatically once Stripe is verified
6. Banner appears on:
   - Dashboard home
   - Bookings page

### AC2: Stripe Setup Status Indicator
1. Sidebar or header shows Stripe status icon
2. Icon indicates: Not Set Up (red), Pending Verification (yellow), Active (green)
3. Clicking icon navigates to Stripe settings

### AC3: Payment Status Documentation
1. Add info tooltip/popover explaining payment statuses:
   - **Pending**: Experience not yet completed
   - **Processing**: Experience completed, payout in progress (2-5 business days)

2. Show estimated payout date where relevant
3. Link to full payment FAQ/help article

### AC4: Stripe Onboarding Reminder
1. If Stripe incomplete for >7 days, send email reminder
2. Email explains importance of completing setup
3. Email includes direct link to resume onboarding

## Technical Details

### Stripe Status Detection

```typescript
// Check Stripe account status
const getStripeStatus = async (wineryId: string) => {
  const winery = await db.winery.findUnique({
    where: { id: wineryId },
    select: { stripeAccountId: true, stripeAccountStatus: true },
  });

  if (!winery?.stripeAccountId) {
    return 'NOT_CONFIGURED';
  }

  // Verify with Stripe API
  const account = await stripe.accounts.retrieve(winery.stripeAccountId);

  if (!account.charges_enabled || !account.payouts_enabled) {
    return 'PENDING_VERIFICATION';
  }

  return 'ACTIVE';
};
```

### Banner Component

```tsx
// StripeSetupBanner.tsx
interface StripeSetupBannerProps {
  status: 'NOT_CONFIGURED' | 'PENDING_VERIFICATION';
  onDismiss?: () => void;
}

export function StripeSetupBanner({ status, onDismiss }: StripeSetupBannerProps) {
  const t = useTranslations('stripe');

  return (
    <Alert variant="warning" className="mb-6">
      <AlertCircle className="h-4 w-4" />
      <AlertTitle>{t('setupRequired.title')}</AlertTitle>
      <AlertDescription>
        {status === 'NOT_CONFIGURED'
          ? t('setupRequired.notConfigured')
          : t('setupRequired.pendingVerification')}
      </AlertDescription>
      <Button asChild className="mt-2">
        <Link href="/dashboard/settings/payments">
          {t('setupRequired.completeSetup')}
        </Link>
      </Button>
      {onDismiss && (
        <Button variant="ghost" size="sm" onClick={onDismiss}>
          {t('common.dismiss')}
        </Button>
      )}
    </Alert>
  );
}
```

## Dev Notes

### Payment Status Rules (for documentation)

| Status | Condition | User-Facing Message |
|--------|-----------|---------------------|
| Pending | Experience date in future | Payment held until experience completion |
| Processing | Experience completed, <5 business days | Payout processing, arriving in 2-5 business days |
| Paid | Experience completed, 5+ business days | Funds transferred to your bank account |
| Refunded | Booking cancelled by visitor | Full amount refunded to customer |

### Stripe Account Status Mapping

| Stripe API Response | App Status | Action Required |
|--------------------|------------|-----------------|
| No stripeAccountId | NOT_CONFIGURED | Complete onboarding |
| charges_enabled: false | PENDING_VERIFICATION | Complete verification steps |
| payouts_enabled: false | PENDING_VERIFICATION | Add bank account |
| Both enabled | ACTIVE | None |

### Banner Dismissal Logic

```typescript
// localStorage key: encave_stripe_banner_dismissed_{wineryId}
const DISMISS_DURATION = 7 * 24 * 60 * 60 * 1000; // 7 days

const isBannerDismissed = () => {
  const dismissed = localStorage.getItem(`encave_stripe_banner_dismissed_${wineryId}`);
  if (!dismissed) return false;
  return Date.now() < parseInt(dismissed) + DISMISS_DURATION;
};
```
