# Story 12.3: Dashboard UI Polish (Dropdowns, Modals & Visual Bugs)

## Status

Draft

## Story

**As a** winemaker using the dashboard,
**I want** consistent and polished UI elements (dropdowns, modals, loading states),
**so that** I can manage my bookings efficiently without visual distractions or confusion.

## Problem Statement

User feedback identified several UI polish issues across the dashboard:

1. **Transparent Dropdowns**: Dropdown menus lack background, making text unreadable
2. **Modal Background Issue**: "View client" modal has background/overlay problems
3. **Export Loading Stuck**: After CSV export, loading indicator doesn't clear
4. **Calendar Date Bug**: When blocking a date, visual effect appears on wrong day (day before)

These issues appear in multiple locations:
- `/dashboard/bookings`
- `/dashboard/experiences/new`

Check for missing state reset in async handler:

## Dev Notes

### Quick Fixes

**Dropdown Background:**
```tsx
// In dropdown-menu.tsx or select.tsx
<DropdownMenuContent
  className="z-50 bg-white border border-stone-200 shadow-lg rounded-md"
>
```

**Modal Overlay:**
```tsx
// In dialog.tsx
<DialogOverlay className="fixed inset-0 z-50 bg-black/50 backdrop-blur-sm" />
<DialogContent className="fixed z-50 bg-white rounded-lg shadow-xl">
```

**Export Loading:**
```typescript
const handleExport = async () => {
  setIsExporting(true);
  try {
    await exportToCSV();
    toast.success(t('export.success'));
  } catch (error) {
    toast.error(t('export.error'));
  } finally {
    setIsExporting(false);  // ALWAYS reset loading
  }
};
```

**Calendar Date Fix:**
```typescript
// Use date-fns with UTC
import { formatISO, startOfDay } from 'date-fns';
import { toZonedTime } from 'date-fns-tz';

const normalizedDate = startOfDay(toZonedTime(selectedDate, 'UTC'));
```
