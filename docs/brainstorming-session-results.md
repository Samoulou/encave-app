## Technique Sessions

### 1. Analogical Thinking - Warm-up

**Description:** Explorer les parallèles avec des plateformes à succès (Airbnb, Booking)

**Ideas Generated:**

1. Modèle marketplace bi-face : demandeur (client) + offreur (encaveur)
2. Réputation construite au fil du temps (avis clients)
3. Qualité de la plateforme et UX/UI moderne
4. Transposition directe : hébergement → expériences vinicoles

**Insights Discovered:**

- Le succès d'Airbnb repose sur la mise en relation de deux personas avec des besoins complémentaires
- La confiance se construit via les avis et la qualité de l'expérience
- L'UX est un différenciateur majeur

**Notable Connections:**

- Viator/GetYourGuide : modèle expériences touristiques
- TheFork : réservation + avis
- Vivino : communauté vin (inspiration pour Phase 2)

---

### 2. Role Playing - Persona Client (Marie)

**Description:** Parcours d'une touriste française cherchant une dégustation

**Ideas Generated:**

1. SEO prioritaire : "dégustation vin valais" doit mener à EnCave
2. Recherche par lieu (Crans-Montana, Fully, etc.)
3. Filtrage par prix, avis, photos, types de vins
4. Événements thématiques différenciants :
   - "Cave + plateau fromage" (grand public)
   - "Discussion vinification avec œnologue" (initiés)
   - "Créez votre assemblage" (expérience unique)
   - "Découverte du vin" (débutants)
5. Guest checkout (pas d'obligation de compte)
6. Paiement en ligne ou sur place
7. Confirmation email avec toutes les infos pratiques

**Insights Discovered:**

- Les critères de choix principaux : prix, avis, photos, types de vins proposés
- L'obligation de créer un compte est un frein majeur
- Les événements thématiques sont un différenciateur fort

**Notable Connections:**

- La personnalisation des événements crée une valeur unique par rapport à une simple réservation

---

### 3. Role Playing - Persona Encaveur (Jean-Pierre)

**Description:** Parcours d'un vigneron de Fully rejoignant la plateforme

**Ideas Generated:**

1. Valeur pour l'encaveur :
   - Flexibilité administrative (focus sur la vigne)
   - Visibilité accrue (marketing fait par la plateforme)
   - Consultation simple de l'agenda
2. Protection contre les no-shows :
   - Paiement 100% en ligne obligatoire
   - Non-remboursable si annulation < 24h
   - Minimum de personnes par événement
3. Onboarding simplifié :
   - Inscription avec infos minimum
   - Vérification avant premier événement (qualité)
   - Self-service ou assisté par IA
4. IA pour l'onboarding :
   - Description cave marketing optimisé
   - Suggestion de prix (indicatif)
   - Génération multilingue (FR/DE/EN)
   - Titres d'événements
   - Recherche automatique des vins → lier aux événements

**Insights Discovered:**

- Les encaveurs sont des artisans du vin, pas des marketeurs
- Le temps est leur ressource la plus précieuse
- L'IA peut résoudre le dilemme scalabilité vs qualité

**Notable Connections:**

- La recherche automatique des vins (via Vivino, sites web, registre AOC) pour faciliter la création d'événements

### 4. What If Scenarios - IA & Expansion

**Description:** Explorer les possibilités futures

**Ideas Generated:**

#### IA Côté Client :

1. Recherche en langage naturel : "J'aimerais créer mon assemblage"
2. Suggestions basées sur les préférences exprimées
3. ❌ Sommelier virtuel rejeté (hors positionnement marketplace)

#### Stratégie d'Expansion :

```
Valais (MVP)
    ↓ même culture, même langue
Suisse Romande (Lavaux, Genève, Neuchâtel...)
    ↓ scalabilité résolue = plus de frontières
Suisse Alémanique
    ↓ partenariats, pub, croissance organique
Europe (Bourgogne, Toscane, Rioja...)
```

#### Modèle de Revenus :

| Source                  | Qui paie | MVP        |
| ----------------------- | -------- | ---------- |
| Commission réservation  | Client   | ✅         |
| Abonnement premium      | Encaveur | ✅         |
| Publicité/mise en avant | Encaveur | ✅         |
| Commission ventes vin   | Encaveur | ❌ Phase 2 |

**Positionnement stratégique :** "On aide l'encaveur, on taxe le client"

#### Risques & Mitigations :

| Risque               | Mitigation                                   |
| -------------------- | -------------------------------------------- |
| Encaveurs réticents  | Améliorer proposition de valeur, prouver ROI |
| No-shows             | Paiement anticipé = encaveur protégé         |
| Copie par concurrent | Focus qualité & exécution                    |

**Insights Discovered:**

- La scalabilité de l'onboarding (IA + self-service) est la clé de l'expansion
- Le positionnement "allié de l'encaveur" est un argument commercial fort
- Le tracking des ventes de vin est complexe → garder pour Phase 2

### 6. First Principles - Synthèse MVP

**Description:** Définition du minimum viable

**MVP EnCave - Version 0.1 :**

#### Côté Client (Web responsive) :

- [ ] Page d'accueil avec recherche (lieu/date)
- [ ] Liste d'événements filtrée
- [ ] Page détail événement + cave
- [ ] Réservation (nombre de personnes)
- [ ] Paiement en ligne (Stripe)
- [ ] Email de confirmation

#### Côté Encaveur (Dashboard simple) :

- [ ] Inscription + vérification manuelle
- [ ] Création événements (type, prix, horaires, capacité)
- [ ] Vue des réservations à venir
- [ ] Notifications nouvelles réservations

#### Plateforme :

- [ ] Gestion paiements (Stripe Connect)
- [ ] Conditions d'annulation (< 24h = non remboursable)
- [ ] Redistribution aux encaveurs

#### Reporté à Phase 2 :

- Page cave avec aide IA
- Vente de vin intégrée
- Cross-selling
- Fonctionnalités Vivino-like
- Réputation client

## Idea Categorization

### Immediate Opportunities

_Ideas ready to implement now_

1. **MVP Core - Réservation en ligne**
   - Description: Système de recherche, réservation et paiement d'expériences vinicoles
   - Why immediate: Cœur de la proposition de valeur, retours encaveurs positifs
   - Resources needed: Stack technique (.NET/Angular ou React), Stripe Connect, hébergement

2. **Événements thématiques**
   - Description: Différencier les types d'expériences (assemblage, dégustation + fromage, etc.)
   - Why immediate: Différenciateur fort, facile à implémenter dans le MVP
   - Resources needed: Templates d'événements, photos de qualité

3. **Validation terrain effectuée**
   - Description: Contacts encaveurs avec retours positifs
   - Why immediate: Validation marché déjà réalisée
   - Resources needed: Formaliser les engagements, premiers partenaires

### Future Innovations

_Ideas requiring development/research_

1. **IA pour l'onboarding encaveur**
   - Description: Génération descriptions, recherche automatique des vins, multilingue
   - Development needed: Intégration API LLM, scraping/API vins, UX conversationnelle
   - Timeline estimate: Phase 2

2. **Recherche en langage naturel**
   - Description: "J'aimerais créer mon assemblage" → résultats pertinents
   - Development needed: NLP, semantic search
   - Timeline estimate: Phase 2-3

3. **E-commerce vin intégré**
   - Description: Vente des vins dégustés post-événement
   - Development needed: Module e-commerce, logistique, tracking
   - Timeline estimate: Phase 2-3

### Moonshots

_Ambitious, transformative concepts_

1. **Expansion européenne**
   - Description: Présence dans les grandes régions viticoles (Bourgogne, Toscane, Rioja)
   - Transformative potential: Devenir LE référent mondial des expériences vinicoles
   - Challenges to overcome: Localisation, scalabilité vérification, concurrence locale

2. **Plateforme communautaire vin**
   - Description: Fusion booking + Vivino (avis, notes, reconnaissance)
   - Transformative potential: Écosystème complet autour du vin
   - Challenges to overcome: Complexité, focus dilué

### Insights & Learnings

_Key realizations from the session_

- **Double proposition de valeur:** Le succès repose sur la satisfaction des DEUX côtés (client ET encaveur)
- **L'encaveur est un artisan:** Il veut se concentrer sur son vin, pas sur l'administratif - c'est notre valeur
- **Scalabilité = IA:** L'aide automatisée permet de maintenir la qualité en grandissant
- **Guest checkout critique:** L'obligation de compte tue la conversion
- **Positionnement stratégique:** "Allié de l'encaveur" est différenciant
- **Vision inspirante:** "En Valais on fait du vin de classe mondial et on doit pouvoir le montrer !"
