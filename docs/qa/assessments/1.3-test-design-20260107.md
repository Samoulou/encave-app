```typescript
describe('createWinery', () => {
  describe('authentication', () => {
    it('returns UNAUTHORIZED when not logged in');
  });

  describe('validation', () => {
    it('returns VALIDATION_ERROR for invalid input');
  });

  describe('business rules', () => {
    it('creates winery with PENDING status');
    it('updates user role to WINEMAKER');
    it('returns CONFLICT for duplicate winery name');
    it('returns CONFLICT if user already has winery');
    it('generates unique slug');
  });

  describe('transaction safety', () => {
    it('rolls back on failure');
  });
});
```

```typescript
describe('WineryAccessGuard', () => {
```

## Summary

**Existing Coverage**: Strong unit test coverage for validation (28 tests in validators + slug)

**Critical Missing**: Integration tests for the core business logic (createWinery action) and security access control (WineryAccessGuard)

**Recommendation**: Before marking story as Done, create integration tests for P0 scenarios to ensure data integrity and security.
