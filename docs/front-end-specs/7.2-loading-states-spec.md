> **Story:** 7.2 - Loading States & Visual Feedback
> **Status:** Draft
> **Author:** Sally (UX Expert)

## 1. Overview

### Purpose

Ce document définit les spécifications UI/UX pour l'implémentation des états de chargement et du feedback visuel dans l'application EnCave. L'objectif est de fournir un retour immédiat à l'utilisateur lors de chaque interaction.

### Scope

| Composant | Description |
|-----------|-------------|
| Navigation Progress Bar | Barre de progression globale pour les transitions de route |
| Button Loading States | États de chargement pour les boutons d'action |
| Skeleton Loaders | Placeholders animés pendant le chargement des données |
| Link Feedback | Feedback visuel sur les liens de navigation |

### Design Principles Applied

1. **Immediate Feedback** - Chaque action a une réponse claire et immédiate
2. **Consistency** - Patterns de loading cohérents dans toute l'application
3. **Accessibility** - Respecte `prefers-reduced-motion` et annonce les états aux lecteurs d'écran
4. **Brand Alignment** - Utilise la palette burgundy/gold du design system EnCave

## 2. Navigation Progress Bar

### 2.1 Visual Specification

```
┌────────────────────────────────────────────────────────────────┐
│ ████████████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │ ← 3px height
└────────────────────────────────────────────────────────────────┘
  Position: fixed top, z-index: 9999
```

### 2.2 Styling

| Property | Value | Notes |
|----------|-------|-------|
| Height | `3px` | Thin but visible |
| Position | `fixed`, `top: 0` | Always visible at top of viewport |
| Z-index | `9999` | Above all content including modals |
| Background | `linear-gradient(90deg, #cc2d55, #ab2046)` | Burgundy gradient (primary brand) |
| Glow Effect | `box-shadow: 0 0 10px #cc2d55` | Subtle burgundy glow |

### 2.3 CSS Implementation

```css
/* globals.css */
#nprogress {
  pointer-events: none;
}

#nprogress .bar {
  background: linear-gradient(
    90deg,
    #cc2d55 0%,      /* burgundy-600 */
    #ab2046 50%,     /* burgundy-700 */
    #cc2d55 100%
  );
  position: fixed;
  z-index: 9999;
  top: 0;
  left: 0;
  width: 100%;
  height: 3px;
  box-shadow: 0 0 8px rgba(204, 45, 85, 0.5);
}

#nprogress .peg {
  display: block;
  position: absolute;
  right: 0;
  width: 100px;
  height: 100%;
  box-shadow: 0 0 10px #cc2d55, 0 0 5px #cc2d55;
  opacity: 1;
  transform: rotate(3deg) translate(0px, -4px);
}

/* Accessibility: Respect reduced motion */
@media (prefers-reduced-motion: reduce) {
  #nprogress .bar {
    transition: none;
  }
  #nprogress .peg {
    display: none;
  }
}
```

### 2.4 Behavior

| Phase | Duration | Progress | Easing |
|-------|----------|----------|--------|
| Start | 0ms | 0% → 8% | instant |
| Trickle | 0-500ms | 8% → 80% | ease-out |
| Wait | 500ms+ | 80% (trickle slowly) | linear |
| Complete | 200ms | 80% → 100% | ease-out |
| Fade out | 150ms | opacity 1 → 0 | ease-out |

### 2.5 Configuration

```tsx

  color="#cc2d55"
  options={{
    showSpinner: false,
    easing: 'ease',
    speed: 300,
    minimum: 0.08,
    trickle: true,
    trickleSpeed: 200,
  }}
  shallowRouting
/>
```

## 3. Button Loading States

### 3.1 Visual States

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   NORMAL:     [ Se connecter ]                              │
│                                                             │
│   LOADING:    [ ○ Connexion... ]  (spinner + text change)   │
│               opacity: 0.8, cursor: not-allowed             │
│                                                             │
│   DISABLED:   [ Se connecter ]                              │
│               opacity: 0.5, cursor: not-allowed             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 Styling Specification

| State | Background | Text | Opacity | Cursor |
|-------|------------|------|---------|--------|
| Normal | `burgundy-600` | White | 1 | pointer |
| Hover | `burgundy-500` | White | 1 | pointer |
| Loading | `burgundy-600` | White | 0.8 | not-allowed |
| Disabled | `burgundy-600` | White | 0.5 | not-allowed |

### 3.3 Spinner Specification

| Property | Value |
|----------|-------|
| Icon | `Loader2` from lucide-react |
| Size | `h-4 w-4` (16x16px) |
| Color | Inherit (white on primary buttons) |
| Animation | `animate-spin` (1s linear infinite) |
| Position | Left of text, `mr-2` margin |

### 3.4 Component Props

```tsx
interface ButtonProps {
  isLoading?: boolean;
  loadingText?: string;  // e.g., "Connexion..." instead of "Se connecter"
  children: React.ReactNode;
  disabled?: boolean;
}
```

### 3.5 Implementation Example

```tsx
<Button disabled={isLoading} className="min-w-[140px]">
  {isLoading ? (
    <>
      <Loader2 className="mr-2 h-4 w-4 animate-spin" />
      {loadingText || 'Chargement...'}
    </>
  ) : (
    children
  )}
</Button>
```

### 3.6 Key Behaviors

- **Width Stability**: Button uses `min-w-[140px]` to prevent size changes
- **Disable on Load**: Always set `disabled={isLoading}` to prevent double-clicks
- **Text Change**: Loading text should indicate action in progress (e.g., "Connexion..." not "Loading...")
- **Spinner Position**: Always left of text for consistency

## 4. Skeleton Loaders

### 4.1 Base Skeleton Component

```tsx
// src/components/ui/skeleton.tsx
import { cn } from '@/lib/utils';

interface SkeletonProps extends React.HTMLAttributes<HTMLDivElement> {
  className?: string;
}

export function Skeleton({ className, ...props }: SkeletonProps) {
  return (
    <div
      className={cn(
        'animate-pulse rounded-md bg-stone-200',
        className
      )}
      aria-hidden="true"
      {...props}
    />
  );
}
```

### 4.2 Animation Specification

| Property | Value |
|----------|-------|
| Animation Name | `pulse` (Tailwind default) |
| Duration | 2s |
| Timing | `cubic-bezier(0.4, 0, 0.6, 1)` |
| Background | `stone-200` (#e7e5e4) |
| Border Radius | `rounded-md` (6px) or match content |

## 5. Navigation Link Feedback

### 5.1 Visual States

| State | Visual Change |
|-------|---------------|
| Default | Normal text color |
| Hover | `text-burgundy-600`, `transition-colors duration-150` |
| Active (current page) | `text-burgundy-600`, `font-medium` |
| Loading (navigating) | `opacity-70`, `cursor-wait`, optional spinner |

### 5.2 NavLink Component Spec

```tsx
// Optional enhanced NavLink with loading state
interface NavLinkProps {
  href: string;
  children: React.ReactNode;
  className?: string;
  showLoadingSpinner?: boolean; // Optional: show inline spinner
}
```

### 5.3 Implementation

```tsx
'use client';

import Link from 'next/link';
import { usePathname } from 'next/navigation';
import { useState, useEffect } from 'react';
import { cn } from '@/lib/utils';
import { Loader2 } from 'lucide-react';

export function NavLink({
  href,
  children,
  className,
  showLoadingSpinner = false
}: NavLinkProps) {
  const pathname = usePathname();
  const [isNavigating, setIsNavigating] = useState(false);

  useEffect(() => {
    setIsNavigating(false);
  }, [pathname]);

  const isActive = pathname === href || pathname.startsWith(href + '/');

  return (
    <Link
      href={href}
      onClick={() => {
        if (pathname !== href) {
          setIsNavigating(true);
        }
      }}
      className={cn(
        'relative flex items-center gap-2 px-3 py-2',
        'text-sm font-medium transition-all duration-150',
        'hover:text-burgundy-600',
        isActive && 'text-burgundy-600 font-semibold',
        isNavigating && 'opacity-70 cursor-wait',
        className
      )}
    >
      {showLoadingSpinner && isNavigating && (
        <Loader2 className="h-3 w-3 animate-spin" />
      )}
      {children}
    </Link>
  );
}
```

## 7. Accessibility Requirements

### 7.1 ARIA Attributes

| Attribute | Usage |
|-----------|-------|
| `aria-busy="true"` | On containers while loading |
| `aria-live="polite"` | For dynamic content updates |
| `role="status"` | For loading status messages |
| `aria-hidden="true"` | On skeleton elements (decorative) |

### 7.2 Screen Reader Announcements

```tsx
// Include visually hidden status text
<span className="sr-only">Chargement en cours...</span>

// Or use aria-label
<div aria-label="Chargement des expériences en cours" aria-busy="true">
```

### 7.3 Reduced Motion Support

```css
@media (prefers-reduced-motion: reduce) {
  .animate-pulse {
    animation: none;
  }

  .animate-spin {
    animation: none;
  }

  #nprogress .bar {
    transition: none;
  }
}
```
