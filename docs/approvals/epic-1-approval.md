## Design System as Official Standard

This approval establishes the Epic 1 Premium Redesign specification as the **official design standard** for all future EnCave development.

### Binding Guidelines

All future development MUST adhere to:

1. **Typography**
   - Display: Playfair Display (headlines, titles)
   - Body: DM Sans (UI text, paragraphs)
   - Monospace: JetBrains Mono (code, data tables)

2. **Color Palette**
   - Primary: Burgundy palette (`burgundy-50` to `burgundy-950`)
   - Accent: Gold palette (`gold-50` to `gold-900`)
   - Neutrals: Warm neutrals (`cream-50/100/200`, `stone-100/200`)

3. **Component Standards**
   - Use premium button variants with gradient and hover effects
   - Cards with warm shadows and `rounded-xl`
   - Inputs with premium styling and burgundy focus rings
   - Verified badges using gold palette

4. **Spacing & Layout**
   - Generous padding (`p-6 sm:p-8` for cards)
   - Max container width `max-w-6xl`
   - Responsive breakpoints as defined in spec

5. **Animation**
   - Motion philosophy: Purposeful, Subtle, Performant
   - Standard easings: `--ease-out`, `--ease-in-out`, `--ease-spring`
   - Always honor `prefers-reduced-motion`

6. **Accessibility**
   - WCAG 2.1 Level AA compliance required
   - Burgundy focus rings (`ring-burgundy-500 ring-offset-2`)
   - Minimum 44x44px touch targets
